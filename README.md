# Rise 360 Slider Interaction

Use `rise360_slider_interaction.html` as a web object in Articulate Rise 360.

## How to use in Rise 360
1. Upload `rise360_slider_interaction.html` to your hosting location (or package it in a zip for a Rise web object).
2. In Rise 360, add a **Web Object** block.
3. Point it to the hosted URL (or uploaded package entry file).
4. Resize the block height to around **700px** for best visibility.

## Customization
- Edit scenario text in the `<section class="scenario">` block.
- Edit **Action A** and **Action B** text in the `.actions` section.
- Change the correct answer by setting `correctDirection` in JavaScript to `'A'` or `'B'`.
